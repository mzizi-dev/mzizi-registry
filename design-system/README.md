# The mzizi design system

The brand book for the mzizi design system. This folder holds:

- `tokens.json`: every token as data. It is generated by `pnpm design-system:generate` from `styles/globals.css` and `lib/tokens/`. Never edit it by hand; `pnpm design-system:generate:check` gates it in CI.
- `marks/`: the official brand marks.
- `components/`: static renditions of the core N2 primitives.

mzizi is the root system beneath the bundu ecosystem: mukoko, nyuchi, shamwari, Mukoko Events and every mini-app. It is warm paper, ink-dark type and the colours of the continent's minerals, with every control shaped as a pill. The philosophy is Ubuntu: _Ndiri nekuti tiri_ — I am because we are.

## Content fundamentals

**Voice.** Speak like a knowledgeable friend, not a corporation. Use simple, clear language, active voice and direct address ("you"). Be warm and encouraging, never condescending. Write for technical and non-technical readers at once, and explain any jargon you use.

**Casing.** Brand wordmarks are always lowercase, even at the start of a sentence: `mzizi`, `mukoko`, `nyuchi`, `bundu`, `shamwari`, `kweli`, `fundi`. Never write "Mukoko" or "NYUCHI" as a wordmark. A product name the canon spells out, such as **Mukoko Events** (formerly nhimbe), is written exactly as `lib/tokens/brand.source.ts` gives it. Use sentence case for UI labels and headings.

**Culture.** Reference African origins and meanings where they matter. Every mineral carries an origin, such as "Merelani Hills, Tanzania". Shona terms stand as first-class words, with the meaning alongside: _Musha_ (home), _Basa_ (work), _Nhaka_ (heritage). Don't assume Western-centric references. Example copy uses African names and places (Tendai, Harare, Book Café).

**No decoration.** Don't use emoji as ornament. Use icons from the icon set instead (see Iconography).

**The covenant test.** Before shipping copy or a feature, ask: does this strengthen the community, or does it extract from it? Never design for addiction, and never let advertisers decide what people see.

## Visual foundations

### Surfaces

- The page is `background`, a warm grey (`#f3f2ee` / `#1b1a17`) covered in the **engineering dot grid**: 1px dots in `dot-color` at the 24px `dot-pitch`, fixed to the viewport. The grid only shows between opaque surfaces.
- Content sits on `card` (white in light; darker than the page in dark). Popovers use `popover`, and modals and sheets use `overlay` over a `scrim`.
- Inset areas (tab lists, metadata rows) use `muted`.
- For elevation-aware layouts, use the rungs: `pitch` → `void` → `surface` → `container` → `raised`.
- Borders are hairlines: `border` is 6% ink. Cards use a ring of `foreground` at 10%. **Separate surfaces with borders, not shadows**; the system defines no shadow tokens.

### Ink and accent

- `primary` is ink: near-black in light, near-white in dark. The default button, checked controls and active states use it. This makes the UI ink-first, with colour reserved for meaning.
- `brand-accent` is the one saturated brand fill per product. The registry default is gold (`#7a5c00` / `#ffd740`), with `brand-accent-foreground` on top. Each product sets it to its own ecosystem mineral (see below).
- Status: `success` (malachite), `warning` (amber), `destructive` (error), `info` (cobalt), `neutral`, `offline`, `syncing`. Destructive actions use a 10% `destructive` tint with `destructive` text, never a solid red block. Always pair a status colour with a word or icon.

### Ecosystem minerals

Every product in the ecosystem owns one mineral, which becomes its `brand-accent`. The canon is the `ecosystem` list in `lib/tokens/brand.source.ts`. As of this writing:

- `copper`: bundu.
- `gold`: nyuchi and every Nyuchi brand (Nyuchi Learning, bushtrade, places, transport, wallet).
- `tanzanite`: mukoko, bytes, pulse.
- `sodalite`: shamwari.
- `malachite`: Mukoko Events, kweli, campfire, novels, health.
- `cobalt`: lingo, planner, news, weather.
- `terracotta`: circles.
- `hematite`: mzizi.

`nhimbe` survives only as a deprecated alias of Mukoko Events. Never use it in new work.

### The 21 colour families

There are three groups of seven, and each colour works in both themes.

- **Seven Minerals** are functional roles. Each comes with `-container` and `-on-container` tokens for chips and callouts:
  `cobalt` (Knowledge — links, CTAs), `tanzanite` (Identity — brand, social), `malachite` (Growth — success), `gold` (Value — rewards), `terracotta` (Community), `sodalite` (Intelligence — AI and shamwari surfaces), `copper` (Stewardship — the bundu commons).
  The minerals fall into two families: **deep-earth** (cobalt, tanzanite, malachite, sodalite) and **hand** (gold, terracotta, copper).
- **Seven Heritage** tones set the atmosphere, not UI state: `indigo`, `savanna`, `baobab`, `sunset`, `river`, `hematite`, `kalahari`. Use them for mini-app moods and cover washes.
- **Experimental Seven** is a computed heptagon of hues offset by 17°: `ember`, `acacia`, `fern`, `lagoon`, `storm`, `dusk`, `protea`. Each has `-container`, `-on` and `-ui` tiers. Use `-ui` only for non-text marks. These colours are for newsroom and exploratory surfaces only.
- To set text in a mineral, put `<m>-on-container` on `<m>-container`. Every one of those pairs clears 9:1. Four raw pairs miss 4.5:1 on `card`: `copper` and `sunset` in light (4.44:1), `kalahari` in light (2.0:1) and `sodalite` in dark (3.7:1). Their token notes spell out the limits.
- Charts use `chart-1`…`chart-5`: tanzanite, cobalt, malachite, gold, terracotta.

### Type

- `sans` is **Noto Sans**, for all body text and UI. It was chosen for its coverage of African languages and diacritics.
- `serif` is **Noto Serif**, for page titles, heroes and display.
- `mono` is **JetBrains Mono**, for code, terminal output, and status labels in uppercase.
- The scale: `display` 72 → `display-small` 60 → `h1` 48 → `h2` 36 → `h3` 30 (all serif, with tight negative tracking), then `h4` 24 → `h5` 20 → `h6` 16 (sans semibold). Body sizes are `body-large` 18, `body` 16 and `body-small` 14, plus `caption` 12 (+0.02em) and `code` 14 (tabular nums). Headings from h1 up are fluid down to their minimum.
- Weights: 400 for body text, 500 (`label`) for nav, form labels, table headers and buttons, 600 for headings, and 700 for display.

### Shape

- **Every button, input, switch and horizontal tab list is a pill** (`radius-full`). This is a brand identity decision.
- Other radii come from a 7px unit, giving the ecosystem numbers 7 / 12 / 14 / 17: `radius-sm` for checkboxes, `radius-md` for inner corners, `radius-lg` for cards, `radius-xl` for dialogs and vertical tabs.
- Media is square by default (`aspect-media`). Use `aspect-media-wide` only for footage that is really 16:9.

### Spacing and density

- Use the `space-*` scale from 2px to 128px. Component padding defaults to `space-base` (16px); `space-base-plus` (20px) gives a comfortable layout. Cards pad with `space-lg` (24px), or `space-base` when compact. Use `space-xl` for page margins and `space-3xl`…`space-6xl` between sections.
- **Touch targets:** 48px minimum (`touch-min`) and 56px by default (`touch-default`). Controls extend their hit area invisibly when they are drawn smaller.

### States and accessibility

- The target is APCA 3.0 AAA. Body text pairs clear 7:1 in both themes.
- **Focus:** on focus-visible, the element's border turns `ring` and a 3px `ring` halo at 50% appears. The ring is ink, so it contrasts with every surface.
- Disabled elements drop to 50% opacity and ignore pointer events. Invalid fields get a `destructive` border with a 20% `destructive` halo.
- Keyboard navigation comes from Radix primitives. Use semantic HTML, and add ARIA only where needed.
- Motion is limited to short colour and transform transitions (~150ms). There is no decorative animation.

## Iconography

- Use **Lucide** (`lucide-react`), re-exported through `@/lib/icons` so a consumer can swap the set. Icons are 16px inside buttons and 12px inside badges, drawn as strokes in `currentColor`.
- Don't use emoji as icons.
- The marks are in `marks/`, each with a light and a dark version. Use the one that matches the theme, and never redraw or recolour a mark:
  - **mzizi**: a seven-node network. Its nodes use `gold`'s values: `#5d4037` on light grounds, `#ffd740` on dark.
  - **bundu**: a copper ring around a root-shaped field.
  - **nyuchi**: the bee.
  - **mukoko**: a honeycomb of the seven minerals.

## Components

The previews in `components/` render the N2 primitives Button, Input, Badge, Card, Switch, Checkbox and Tabs as static HTML, styled by `components/bundle.css` (classes `.mz-*`). The production React components live in the registry and install with `npx shadcn@latest add https://api.mzizi.dev/v1/ui/<name>`, and use the same token names as CSS custom properties.
