# Superseded — The 3D Architecture Model

> **Status:** superseded in version 4.1.0 by the **Mzizi DNA Helix** model.

This page described the system as a three-dimensional model with X / Y / Z axes plus outlier actors. That framing has been replaced by the DNA helix — which expands by adding strand components without redefining a dimension.

## Where the model lives now

- **Mzizi DNA Helix** — the framework's genetic code, defined by the collections in `component_documents`.
- **Locked properties:** see the [DNA helix doctrine docs](/documentation/dna-helix-overview) (forthcoming) and the live helix in [the changelog entry for 4.1.0](/changelog/4.1.0).
- **Per-node detail:** see `documentation-architecture-nodes` (current node catalogue; some node names still being migrated to DNA terms).

## Why the change

The 3D model worked for the initial 10-node ecosystem but required a re-explanation every time a node was added (was it horizontal? vertical? depth? outlier?). The helix has named strand components — core, shipped, swappable, genetic-code, machinery, documentation — and adding a new piece doesn't force a re-definition of a dimension.
