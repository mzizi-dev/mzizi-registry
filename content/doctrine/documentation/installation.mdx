# Installation

## Prerequisites

- Node.js 18+
- Next.js 14+ (App Router)
- Tailwind CSS 3.4+

## Install the CLI

```bash
npm install -g @nyuchi/design-cli@latest
```

## Initialize in your project

```bash
npx @nyuchi/design-cli@latest init
```

This will:
1. Create `components.json` configuration
2. Set up the `@/lib/utils` helper with `cn()` function
3. Configure Tailwind with Nyuchi design tokens
4. Install the seven African minerals color palette
5. Set up the Noto Serif / Noto Sans / JetBrains Mono font stack

## Add components

```bash
# Add individual components
npx @nyuchi/design-cli@latest add button card dialog

# Add a full node
npx @nyuchi/design-cli@latest add --node 3

# Add all components for a mini-app
npx @nyuchi/design-cli@latest add --mini-app wallet
```
