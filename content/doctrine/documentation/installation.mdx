# Installation

## Pick a build

Every component has one contract and up to three builds. Astro is the default; the
others are the same component for projects that are not on Astro.

| Build           | For                        | Served at                                 |
| --------------- | -------------------------- | ----------------------------------------- |
| Astro (default) | Astro sites and apps       | `https://api.mzizi.dev/v1/astro/<name>`   |
| Rust (Dioxus)   | Rust apps, via Mzizi Roots | crates.io (`mzizi-roots` and node crates) |
| React           | React and Next.js projects | `https://api.mzizi.dev/v1/ui/<name>`      |

Web builds use Tailwind CSS 4 and the Mzizi tokens. Not every component has every
build yet: `GET https://api.mzizi.dev/v1/astro` lists the Astro ones.

## Add components

```bash
# Rust (Mzizi Roots): the UI side, or one node crate
cargo add mzizi-roots

# React, with the shadcn CLI
npx shadcn@latest add https://api.mzizi.dev/v1/ui/button

# The Mzizi installer resolves a component and its dependencies
npx @nyuchi/mzizi-cli add button --target rust
```

For Astro, fetch the document at `/v1/astro/<name>`: it lists the `.astro` file, its
flat imports as further `/v1/astro/` dependencies and its npm dependencies, written
into `src/components/mzizi/`. Use `@nyuchi/mzizi-cli add <name> --target astro` once
your installed CLI lists `astro` under `--target`.

Every install carries the canonical typography (Noto Sans / Noto Serif / JetBrains
Mono) and the Mzizi palette.
