# Superseded — Frontend Architecture (Four Axes, Ten Nodes)

> **Status:** superseded in version 4.1.0 by the **Mzizi DNA Helix** model.

This page described the system as four axes containing ten nodes, with doctrine stored in `public.architecture_frontend_axes` and `public.architecture_frontend_layers`. Both have moved to the `legacy` schema (4.1.3) and are scheduled for removal after the full cutover.

## What replaced this

| Old | New |
| -- | -- |
| `public.architecture_frontend_axes` | doctrine documents in `documentation-architecture-axes` (4 axis docs flagged superseded; the strand model is the active doctrine) |
| `public.architecture_frontend_layers` | doctrine documents in `documentation-architecture-nodes` (node catalogue) |
| `get_layer_counts()` | `get_system_counts()` (live counts from `component_documents`, no hardcoded numbers) |
| Numbered nodes (N1–N10) | Named collections (`styling`, `primitives`, `accessibility`, `resilience`, `observability`, `fundi`, `brand`, `pages`, `shell`, `documentation`) |
| Layer 3D framing | Mzizi DNA Helix model (core / shipped / swappable / genetic-code / machinery / documentation) |
