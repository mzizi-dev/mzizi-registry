# Mzizi

Mzizi (Swahili for _root_) is the open design system, component registry and DNA-helix frontend architecture of the bundu ecosystem. It is governed by Mzizi and operated and developed by Nyuchi. It is the foundation of Mukoko (Africa's super app), the Nyuchi Web Services developer platform and every Nyuchi Africa product, and anyone in the bundu ecosystem can build on it. Earlier versions of this documentation called it the Nyuchi Design System.

## Philosophy

Built on Ubuntu — "I am because we are." Every component, every token, every decision is made with the community in mind. The system is open source and designed for anyone to use, extend, and contribute to.

## The Seven African Minerals

Our color palette is seven minerals dug from African earth. Each carries a one-word ROLE — the role is a contract, not a mood — and the seven split into two families (deep-earth and hand). Full doctrine: `genetic-code-conventions/seven-minerals`.

Deep-earth family (cool, luminous):

- **Cobalt** — Knowledge. Katanga Copperbelt, DRC & Zambia.
- **Sodalite** — Intelligence. Kunene River, Namibia & South Africa.
- **Tanzanite** — Identity. Merelani Hills, Tanzania.
- **Malachite** — Growth. Congo Copper Belt.

Hand family (warm, grounded):

- **Gold** — Value. Ghana, South Africa, Mali, Zimbabwe.
- **Copper** — Stewardship. Central African Copperbelt, Zambia & DRC.
- **Terracotta** — Community. Pan-African Sahel.

The minerals are one of three groups of seven: with the seven heritage tones and the seven experimental colours, the palette has 21 colour families. Their canonical hex values, container colours, roles and families are in `lib/tokens/palette.source.ts`, the one source of the palette; `pnpm tokens:sync` generates every token artifact from it. Read them with `GET https://api.mzizi.dev/v1/brand` or the `mzizi_get_tokens` MCP tool rather than copying values from a page.

## Architecture

Mzizi is a DNA double helix: two entwined backbones, held together by cross-cutting rungs.

- **Engineering backbone.** Its strands carry the nodes: core-guarantee (N2 Primitives, N4 Safety, N5 Resilience, N8 Assurance), shipped (N3 Brand, N6 Pages, N7 Shell) and swappable (N1 Tokens), with the harness as the spine.
- **Meaning backbone.** The genetic code (the Ubuntu doctrine and the Mzizi conventions) and transcription (doctrine as data).
- **Rungs.** N9 Fundi (self-healing), N10 Documentation (this node), N11 Discovery and N12 Skills bridge both backbones.

Node numbers are labels, not a sequence. Read the live model with `GET https://api.mzizi.dev/v1/architecture` or the `mzizi_get_architecture` MCP tool; `documentation/dna-helix-overview` explains it in full.

## Where everything lives

Mzizi has no database behind it. The registry repository, `mzizi-dev/mzizi-registry`, is the whole data layer, and every change to it is a pull request:

- **Components** — one file per build under `components/registry/n<N>-<node>/`: `.astro` (the default), `.rs` (Mzizi Roots, Dioxus) and `.tsx` (React), each held to the component's one contract under `contracts/`. `registry.json` indexes them.
- **Design tokens** — `lib/tokens/palette.source.ts` (the palette) and `lib/tokens/brand.source.ts` (semantic colours, typography, spacing, the ecosystem brands).
- **Doctrine** — `content/doctrine/`, this page included, inlined into `lib/doctrine.generated.ts` by `pnpm doctrine:generate`.
- **AI instructions and skills** — `content/doctrine/ai-instructions/`; the agent skills are published as `@nyuchi/mzizi-skills`.
- **Changelog** — `CHANGELOG.md`, with the machine-readable release record in `content/changelog/releases.json`.

api.mzizi.dev and mcp.mzizi.dev serve these files from a pinned registry commit. Machine-written data, such as component version history and usage telemetry, belongs to the Mzizi console (app.mzizi.dev), not to the registry.

No page states a count, because counts drift. For the live shape of the system, read `GET https://api.mzizi.dev/v1/stats`, or `meta.registryTotal` on `GET https://api.mzizi.dev/v1/ui`.

## Quick Start

```bash
# React, with the shadcn CLI
npx shadcn@latest add https://api.mzizi.dev/v1/ui/button

# Rust (Mzizi Roots)
cargo add mzizi-roots
```

Astro is the default build: see `documentation/installation` for the Astro, Rust and React install paths. Visit [mzizi.dev](https://mzizi.dev) for the full component library.
